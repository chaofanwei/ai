# Dash 接口耗时统计

统计时间：2026-07-08 至 2026-07-14，按 Asia/Shanghai 自然日。

统计口径：dash 服务端全量。

Prometheus 数据源：

```text
http://starmap.qiyi.domain/ops/prometheus/dash
```

核心指标：

```promql
http_request_duration_seconds_bucket{api="dash"}
http_request_duration_seconds_count{api="dash"}
http_request_duration_seconds_sum{api="dash"}
```

分位数 PromQL 示例：

```promql
histogram_quantile(
  0.9999,
  sum(increase(http_request_duration_seconds_bucket{api="dash"}[1d])) by (le)
) * 1000
```
