# 云闪付 - 相册二维码扫码支付

本文记录在 Android 手机上，通过云闪付 App 从相册选择收款码并进入付款流程的手动/adb 操作步骤。

对应 App 包名：`com.unionpay`

## 前置条件

- 手机已通过 USB 连接，`adb devices` 显示 `device`
- 手机已开启 USB 调试（安全设置），支持 adb 点击操作
- 手机分辨率参考：`1080x2340`（本文坐标基于此设备验证）
- 若手机黑屏或锁屏，先执行：

```bash
./unlock.sh
```

## 启动云闪付

可先查包名：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell pm list packages | rg -i 'union|yun|pay|china|up'
```

启动云闪付：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell monkey -p com.unionpay -c android.intent.category.LAUNCHER 1
```

## 操作流程

### 1. 首页点击「扫一扫」

云闪付首页顶部第一排有「收付款 / 出行 / 扫一扫 / 转账」。

「扫一扫」按钮中心坐标：

```text
(675, 330)
```

点击：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 675 330
```

### 2. 相机页点击「相册」

进入扫码相机界面后，右下角有「相册」按钮。

「相册」按钮中心坐标：

```text
(925, 1900)
```

点击：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 925 1900
```

### 3. 相册页选择二维码照片

进入相册「最近项目」后，第二行前三张照片中心坐标记录如下：

| 位置 | 中心坐标 |
|------|----------|
| 第二行第 1 张 | `(135, 630)` |
| 第二行第 2 张 | `(405, 630)` |
| 第二行第 3 张 | `(675, 630)` |

本次选择第二行第 2 张：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 405 630
```

### 4. 照片确认页点击「确定」

进入相片确认页面后，右上角红色「确定」按钮中心坐标：

```text
(955, 180)
```

点击：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 955 180
```

### 5. 付款页输入金额并确认支付

进入「向商家付款」页面后，数字键盘会自动弹出。

本次输入金额：`89` 元。

数字键盘坐标：

| 按键 | 中心坐标 |
|------|----------|
| `8` | `(405, 1980)` |
| `9` | `(665, 1980)` |
| 确认支付 | `(930, 1970)` |

点击：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 405 1980
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 665 1980
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 930 1970
```

点击「确认支付」后会进入支付密码小弹窗。

## 支付密码

支付密码属于支付认证信息，需要人工在手机上输入。不要在脚本或文档中记录、代输或明文保存支付密码。
