# 美团扫码支付

本文记录在 Android 手机上，通过美团首页扫码入口，选择相册中的付款码图片并完成向商家付款的流程。

## 用途

用于从美团 App 首页进入扫码支付界面，选择手机相册里的二维码图片，识别后进入“向商家付款”页面，再输入金额并确认支付。

本流程会触发真实付款，执行前必须确认商家、金额和二维码来源。

## 前置条件

- 手机已通过 USB 连接，`adb devices` 显示 `device`
- 手机已开启 USB 调试（安全设置），支持 adb 点击
- 手机分辨率参考：`1080x2340`
- 若手机黑屏或锁屏，先执行：

```bash
./unlock.sh
```

美团包名：

```text
com.sankuai.meituan
```

启动美团：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell monkey -p com.sankuai.meituan -c android.intent.category.LAUNCHER 1
```

## 完整流程

1. 打开美团 App。
2. 在首页右上角点击扫码图标。
3. 进入相机扫码界面。
4. 点击右下角图片按钮，进入选择照片页面。
5. 点击顶部“相册”标签。
6. 点击相册列表里的“收藏”一行。
7. 在收藏相册中选择目标二维码照片。
8. 美团识别二维码后进入“向商家付款”页面。
9. 确认商家名称和金额输入框。
10. 输入付款金额。
11. 点击“确认支付”。
12. 确认页面显示“支付成功”。

## 关键坐标

以下坐标基于 `1080x2340` 分辨率，页面布局变化时需要重新截图确认。

### 美团首页

- 右上角扫码图标：约 `(1000, 155)`

### 相机扫码界面

- 右下角图片按钮：约 `(1000, 1820)`

点击右上扫码图标后，本次没有先进入独立“付款码”页，而是直接进入相机扫码界面。底部显示“扫一扫 / 拍照购”，中间提示“扫二维码/条码/搜同款”。

## 注意事项

- 这是支付操作，会产生真实资金流水。输入金额和点击“确认支付”前要再次确认商家名称。
- 如果支付前出现密码、指纹、人脸、风控弹窗或其他安全验证，不要自动继续，应交给用户本人处理。
- 坐标只能作为当前设备和当前 UI 的经验值；美团首页、照片选择器、键盘布局变化后需要重新截图定位。
- 如果点右上扫码入口后不是相机界面，而是其他“付款码”或扫码支付页面，应先根据页面文案重新确认下一步入口。
- 收藏相册里的照片顺序可能变化，选择前应截图确认目标二维码图片位置。
