# 差客/差旅无忧 - 自动切换登录账号

本文记录在 Android 手机上，于差客 App 的两个测试账号之间自动切换登录的完整流程、技术要点与排错方法。

对应脚本：`chake-switch-account.py`

## 背景与用途

差客 App（包名 `com.slwy.shanglvwuyou`）用于测试，需要在两个固定账号之间来回切换。脚本会自动：

1. 识别当前已登录的是哪个账号
2. 退出当前账号
3. 登录另一个账号
4. 再次验证切换结果

**两个账号密码相同**，脚本内已配置，无需每次手动输入。

## 完整自动化流程

```text
准备 App
  ├─ 前台不是差客 → 启动差客 App
  ├─ 前台已是差客 → 不杀进程，直接继续
  └─ 底部 Tab 没有「我的」
        ├─ 按返回键，最多 3 次
        └─ 仍失败 → force-stop 并重启 App

进入「我的」
  └─ 读取「您好，<姓名>」→ 确定当前账号

退出登录
  ├─ 账号安全
  ├─ 退出登录
  └─ 确认弹窗「确定退出登录？」→ 点「确定」

登录目标账号
  ├─ 确保处于「账号密码登录」模式（非短信登录）
  ├─ 手机号：u2 set_text 填入
  ├─ 密码：剪贴板 + 粘贴（保留大小写）
  ├─ 勾选隐私政策
  └─ 点击「登录」

验证
  ├─ 等待进入首页（「首页」「我的行程」等）
  └─ 再次进入「我的」，确认「您好，<姓名>」已是目标账号
```

## 技术方案说明

### 为什么用 uiautomator2，而不是纯 adb

切换账号脚本 **全程使用 uiautomator2**：

| 能力 | 实现方式 |
|------|----------|
| 读界面 | `dump_hierarchy()` |
| 点击 / 滑动 | `click()` / `swipe()` |
| 填手机号 | `set_text()` |
| 填密码 | `set_clipboard()` + `KEYCODE_PASTE` |
| 启停 App | `app_start()` / `app_stop()` |

### 密码为什么必须剪贴板粘贴

实测 `adb shell input text Claw8801` 会把字母变成 **`CLAW8801`**（全大写），导致登录失败。

正确做法：

1. uiautomator2 写入剪贴板（保留 `Claw8801` 大小写）
2. 焦点在密码框时发送 `KEYCODE_PASTE` 粘贴

手机号只有数字，可直接 `set_text`，无需剪贴板。

### App 启动策略（默认不重启）

与早期脚本不同，切换账号 **默认不会 force-stop**：

- 前台已是差客 → 继续在当前进程操作
- 前台不是差客 → `app_start` 启动（不先杀进程）
- 底部没有「我的」Tab → 最多返回 3 次；仍不行才重启 App
- 仅 `--relaunch` 时才会强制冷启动

这样更快，也避免不必要的登录态丢失。

## 注意事项

- **切换前必须已登录**其中一个配置账号；若停在登录页，脚本无法识别当前账号，会报错退出。
- **执行时间**：整段切换约 20～60 秒，10 分钟内都算正常，不要强行中断。
- **图片验证码**：多次登录失败后会弹出图片验证码，脚本检测到会停止；需人工登录成功一次后再跑自动化。
- **账户或密码错误**：脚本会识别弹窗并报错，检查密码配置或 App 是否改了登录方式。
- **新增账号**：在 `chake-switch-account.py` 的 `ACCOUNTS` 字典里添加姓名和手机号；当前逻辑是「两个账号互切」，超过两个需改 `other_account()` 逻辑。
- **调试 UI**：可用 `dump_window.py` 导出当前界面 XML 分析控件：

```bash
/Users/weichaofan/miniconda3/envs/py3.11/bin/python dump_window.py window_debug.xml
```

## 常见问题

### 报错：not logged in

当前在登录页，没有已登录会话。先手动登录任一测试账号，或确认 App 未意外退出。

### 报错：could not find greeting on 我的 page

「我的」页未出现「您好，\<姓名\>」。可能页面未加载完、账号展示文案变化，或不在「我的」页。

### 报错：could not reach main tab bar with 我的 after relaunch

返回 3 次且重启 App 后，仍找不到底部「我的」Tab。检查 App 是否卡死、弹窗遮挡、或 UI 结构变更。

### 报错：login blocked by image captcha

出现图片验证码。手动完成一次登录后重试。

### 切换成功但验证姓名不对

检查「我的」页问候语格式是否仍为 `您好，<姓名>`；姓名必须与 `ACCOUNTS` 中的 key 完全一致。
