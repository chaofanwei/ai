# 差客/差旅无忧 - 自动申请退款流程

本文记录在 Android 手机上进入商旅 App 的贵宾 VIP 卡订单列表，并批量处理可申请退款订单的步骤。

## 前置条件

- 手机已通过 ADB 连接，设备状态为 `device`。
- 如手机黑屏或锁屏，先执行：

```bash
./unlock.sh
```

- App 包名：

```text
com.slwy.shanglvwuyou
```

- ADB 路径：

```text
/Users/weichaofan/Library/Android/sdk/platform-tools/adb
```

## 1. 启动 App

自动脚本会先通过 `dumpsys window` 和 `dumpsys power` 判断屏幕状态：

- 若检测到锁屏、息屏、Doze 或 Keyguard 输入受限，会先调用：

```bash
./unlock.sh
```

- 若检测到已解锁，则跳过解锁步骤。

如果手机曾经在锁屏状态下启动过 App，解锁后 App 可能会卡在启动页。每次自动操作前先强制停止 App，再重新启动：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell am force-stop com.slwy.shanglvwuyou
```

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell monkey -p com.slwy.shanglvwuyou -c android.intent.category.LAUNCHER 1
```

启动后通常进入首页。

自动脚本执行方式：

```bash
/Users/weichaofan/miniconda3/envs/py3.11/bin/python chake_refund.py --execute
```

如果只想从当前页面开始扫描，不重新启动 App、不判断锁屏：

```bash
/Users/weichaofan/miniconda3/envs/py3.11/bin/python chake_refund.py --start-current
```

## 2. 进入“我的”页面

底部导航栏的“我的”真实点击区域较低，推荐点击坐标：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 898 2098
```

确认进入“我的”页后，页面上方“我的订单”里左上第一个入口是“贵宾VIP卡”。

## 3. 进入“贵宾VIP卡订单列表”

点击“贵宾VIP卡”入口：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 165 732
```

进入后标题应显示：

```text
贵宾VIP卡订单列表
```

## 4. 移动右上角悬浮窗

右上角“自动支付”悬浮窗会挡住订单状态。进入订单列表后，先拖到左侧：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input swipe 820 330 180 330 700
```

这样右侧的订单状态，如“等待确认”“预订取消”“申请退款”“已退款”，可以看清。

## 5. 检查订单状态

用 UIAutomator 读取当前页面文字和坐标：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell uiautomator dump /sdcard/window.xml
/Users/weichaofan/Library/Android/sdk/platform-tools/adb exec-out cat /sdcard/window.xml
```

推荐用 Python 解析可见状态：

```bash
/Users/weichaofan/miniconda3/envs/py3.11/bin/python -c "import subprocess,xml.etree.ElementTree as ET,re; ADB='/Users/weichaofan/Library/Android/sdk/platform-tools/adb'; xml=subprocess.check_output([ADB,'exec-out','cat','/sdcard/window.xml']); root=ET.fromstring(xml); 
for n in root.iter('node'):
 t=n.attrib.get('text','')
 if t and (t.startswith('2026-') or t in ['申请退款','已退款','预订取消','等待确认']):
  b=n.attrib.get('bounds'); nums=list(map(int,re.findall(r'\d+',b or ''))); vis=len(nums)==4 and nums[2]>nums[0] and nums[3]>nums[1] and nums[3]>245 and nums[1]<2070
  if vis: print(t,b,n.attrib.get('clickable'))"
```

## 6. 下滑规则

不要整屏大幅滑动，容易跳过夹在两屏之间的订单按钮。使用约 3/4 屏高度，并保留重叠区域：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input swipe 540 1700 540 850 650
```

每次滑动后重新 dump UI 并检查可见文字。

## 7. 处理“申请退款”

如果当前可见区域出现：

```text
申请退款
```

根据 UIAutomator 解析出的 `bounds` 计算中心点点击。示例：如果按钮坐标是 `[745,1858][990,1960]`，点击中心约为：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 867 1909
```

点击后可能出现两种情况：

1. 进入“申请退款订单”页面，页面上有“提交申请”按钮。
   - 点击“提交申请”。
   - 出现“提交成功”弹窗后点击“确定”。

2. 直接弹出提示：

```text
申请退款订单已经提交，请耐心等待平台处理。
```

这表示该订单已经申请过退款，无需重复提交。点击“确定”后继续往下检查。

“确定”按钮通常可通过 UIAutomator 找到，常见坐标范围为 `[123,1143][957,1283]`，可点中心：

```bash
/Users/weichaofan/Library/Android/sdk/platform-tools/adb shell input tap 540 1213
```

## 8. 停止条件

继续按 3/4 屏重叠下滑检查，直到出现：

```text
已退款
```

看到“已退款”后停止，不再继续往下滑。按照当前业务规则，出现“已退款”表示该订单及更早订单都已经退款过。

## 9. 注意事项

- 如果“申请退款”按钮贴近屏幕底部，点击可能不稳定；先轻微调整列表，让按钮处于屏幕中部后再点击。
- 如果点击后弹窗很快自动关闭，可再次点击该“申请退款”按钮；若提示“申请退款订单已经提交”，点击“确定”并把该订单视为已处理。
- 如果某次命令因为 ADB daemon 权限问题失败，避免用 `sleep; adb ...` 这种组合命令，改用单独 ADB 命令执行。
- 当前流程使用的是设备实际分辨率坐标，手机分辨率为 `1080x2340`，App 可操作内容高度约到 `2135`。
