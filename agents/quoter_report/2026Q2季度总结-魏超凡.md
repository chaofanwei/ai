# 2026 Q2 季度总结 — 魏超凡

> 基于 2026Q2 周报（20260404 ~ 20260605，共 10 周）汇总。周报中加黑部分为当周重点，本总结优先提炼此类内容。

---

## 一、季度概览

Q2 播放服务团队的工作主线可以概括为三条：**播放链路级巡检体系从 0 到 1 落地**、**国际站架构升级（QSM / 网关 / 内网域名）全面收官**、**2026H1 压测验证 QSM 长链接收益并反哺线上限流与稳定性**。

季度内 VRS 整体流量稳中有升：点播主站平均 QPS 从 4 月初约 27~28k 增长至 6 月末约 29~30k；国际站点播 QPS 增幅明显（6 月国际站平均 QPS 约 1.0k，同比前周 +29%）。重点直播保障包括 U17 亚洲杯决赛（峰值 QPS 237）、欧冠决赛（峰值 QPS 6.25k）、电商直播《小奇优选》（峰值 QPS 260）等，均平稳支撑。

## 二、核心成果（季度重点）

### 1. 播放链路级巡检体系 — 客户端侧（面向用户反馈与小流量）

**乐客用户反馈自动收集与智能分类（VIDEODEV-5737）**

- Q2 从原型 → 线上运行 → 测试环境稳定运行，完成能力闭环
- 支持主站和国际站独立运行；流程：监听乐客反馈 → 模型归类 → Grafana 展示 + Hubble 报警
- 5 月跑存量反馈：单日分析 4000+ 条主站反馈，验证分类能力
- 模型侧：切换自建千问 3.6；后续升级为 DeepSeek-V3 + Qwen2.5-72B-Instruct，增加二次审核 subAgent
- 分类优化：**只关注视频播放相关问题，增加二级分类黑名单机制及 TOP 20 保存与报警**，运行稳定（9 个视频播放相关二级分类 + 2 个黑名单分类）
- 报警规则：1h/3h 增量阈值 + 同比昨天同期阈值；页面待迁移至狂飙运维平台（VIDEODEV-5826）

**金丝雀小流量场景覆盖（VIDEODEV-5613 / VIDEODEV-5855）**

- 一期已上线：每晚 8:30 拉取日志、9:00 执行对比
- 二期已上线（VIDEODEV-5855）：数据源支持 Venus 定期查询 + 人工输入；每小时自动对比；页面增加上下线状态、最近对比时间等
- 国际站对比能力重启：点播国际站对比已启动（VIDEODEV-5796）；**直播国际站对比已上线**（VIDEODEV-5850），端覆盖度约 40%（phone 安卓 / tv 安卓 / pcw）

**金丝雀固定 Case 测试机制（VIDEODEV-5797）**

- 监控开发完毕；Atlas 定期回归测试（2h 一次），结果回调星图展示
- 精简 case 后拨测成功率从较低水平提升至 **100%**
- 后续报警处理流程（VIDEODEV-5812）开发中：固定 case 失败时阻塞 VRS 线上发布，待测试确认后解除

### 2. 播放链路级巡检体系 — 服务端侧（面向架构与链路）

**Dash/Live 访问后端 QSM 改造（VIDEODEV-5764）— 季度最大架构项**

- 改造目标：dash/live 访问后端改为 **QSM 主 + Service IP 备**
- 范围：mus、drm、vp 服务（会员接口国际站暂不支持 QSM）
- Q2 进展：代码上线 → 分机房逐步灰度 → **季度末已全量**
- 线上收益（0630 统计，1+2 月 vs 4+5 月，3 月开启 QSM 请求会员）：
  - 请求会员 QPS：7855 → 6598，**下降约 16%**
  - 平均耗时：19.12ms → 16.23ms，**下降约 15%**
  - P99 耗时：56.05ms → 49.10ms，**下降约 12%**

**国际站内网域名切换网关（VIDEODEV-5777 / VIDEODEV-5813）**

- 新内网域名 `intel2-cache.video.qiyi.domain` 已申请，nginx-conf **已上线**
- Dash 代码兼容新域名逻辑 **已上线**；PCW、国际站 TV 后台等对接方 **已开发完毕并上线**
- 老内网域名请求降至约 20/min（pcw/h5），**已发邮件申请下线，评估可下线**；计划半年/一年后正式下线

**QSM 长链接 upstream 优化（VIDEODEV-5820）**

- 问题：qsm upstream 默认 max_fails=1，单次超时会将 upstream 标记不可用 10s，引发 "no live upstreams"
- 改进：设置 max_fails=0，关闭被动健康检查 → **已上线**

**镜像构建配置中心集成（VIDEODEV-5784）**

- 新迁移到配置中心的配置数据加入镜像 → **已上线**

**星图单机部署支持国际站 qpaas（VIDEODEV-5824）— 已完毕**

## 四、故障与复盘

### 4 月 23 日 — 国际站网关非法 x-real-ip
- **现象**：st-1500 报警
- **临时解决**：网关回退升级
- **长期**：dash/live 对非法 IP 不再使用，并增加监控报警（VIDEODEV-5776 相关）

### 5 月 11 日 — 国际站 QSM 网格加入后鉴权失败
- **现象**：付费视频鉴权 st-800，最高错误率 0.16%（未触发报警）
- **原因**：QSM 给 80 端口出请求加 2KB header，与用户 header 合计超 8KB，会员 nginx 返回 400
- **影响**：配置上线因此阻塞，待乐客反馈接入后再启动 QSM 全量

### 会员鉴权 no live upstreams
- **现象**：排查 st-800 时发现 dash 请求会员报 no live upstreams
- **原因**：qsm upstream max_fails 默认 1
- **解决**：VIDEODEV-5820 设置 max_fails=0 → **已上线**
