# VIDEODEV-5891 dash-海外黑产流量封禁

## 背景

海外黑产流量使用固定 `src=01080031010000000000` 发起 `/dash` 请求，需要结合
用户 IP 和登录状态进行临时封禁。已登录用户不封禁，未登录请求命中后返回
`code=A00404`。

需求链接：http://pms.qiyi.domain/browse/VIDEODEV-5891

第一次改版的 IP 清单为 `/data/blockips`，共 1000 条 `x.x.x.*` C 段数据。
第二次改版替换为 `/data/all.ip.txt`，本地原文件位于
`~/Downloads/2026-07-30.all.ip.txt`。新清单实际包含 3,372,184 条完整 IPv4。

## 实现分支

基于最新 `master`（`f985392ab`）新建分支：

`fan_5891_oversea_abuse_block`

## 改动内容

本需求为临时改动，为便于后续手工同步和回收，代码集中修改
`vis-rule-engine/src/main/lua/p911/rules/pre/pre_check.lua`：

- 每个 worker 首次遇到目标 `src` 且 uid 为空的请求时，从
  `/data/all.ip.txt` 读取完整 IPv4，并在内存中缓存；后续请求不再
  读取文件。
- 将每个 IPv4 转换为 `uint32_t`，通过分块数组保存并使用二分查找精确匹配。
  337 万条 IP 的数据内存约为 13 MB/worker，避免大型 Lua 哈希表带来的额外
  内存开销。
- 文件读取失败、存在非法 IPv4、未按 IP 数值升序排列或未解析到有效 IP 时记录
  错误日志并放行，当前 worker 不再重试。
- 成功加载后通过 INFO 日志打印有效 IP 数量和文件路径。
- IP 清单更新后，需要 reload/restart OpenResty worker 才会重新加载。
- 同时满足以下条件时返回 `code=A00404`：
  - `src` 等于 `01080031010000000000`；
  - `uid` 为空；
  - `request.ip` 精确命中新清单中的完整 IPv4。
- 不匹配 `xff_ip`。
- 专用错误响应直接在该文件内构造，未修改公共 `response_utils.lua`。

## 影响范围

- 仅影响满足上述三个条件的 `/dash` 请求。
- 其他 `src`、已登录请求、未命中 IP 的请求保持原有流程。
- 文件异常时按放行处理，当前 worker 生命周期内不再加载。
- 每个 worker 第一次处理目标请求时需要加载清单；本地完整清单实测约 1.34 秒。
- 临时改动不计划合入 `master`，完成本地检查后手工同步到远程服务器。
