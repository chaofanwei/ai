## 2. 已尝试路径与结论

### 2.1 手机 ADB（效果有限，可不再优先）

- 自动点开相册 / 保存不稳定：UI dump 失败、误点会议/其他会话、灰图占位、图片加载卡住。
- 曾拉取手机相册 `/sdcard/DCIM/WeixinWork`（约 143 张）到项目 —— **不是**按聊天月份分组的来源。
- 按 `mmexport` 时间戳分月 **不正确**（用户已确认）。

### 2.2 Mac 企业微信本地缓存（当前主路径 ✅）

#### 这是什么（容易误解，先说清楚）

**不是**「把手机日志直接拷到 Mac 的某个目录」。

实际过程是：

1. 在 **Mac 企业微信**登录同一账号，并做了 **部分聊天记录迁移/同步**（手机 → 电脑）。
2. 迁完后，**Mac 客户端**在自己的沙盒里生成本地数据，路径大致为：

```text
~/Library/Containers/com.tencent.WeWorkMac/Data/Documents/Profiles/<账号ID>/
```

本机账号目录：

```text
~/Library/Containers/com.tencent.WeWorkMac/Data/Documents/Profiles/204D5660AC6464CD45F5EFBC53C6AC1A/
```

| 内容 | 说明 |
|------|------|
| `Messages1/` 等 | 会话/消息库（**加密**，不是明文聊天日志） |
| `Caches/Images/YYYY-MM/` | 已在 Mac 上加载过的聊天**图片缓存**（JPG/PNG，可读） |

要点：

- 数据由 **Mac 企微自己落盘**，不是手机系统直接写文件。
- **不是**完整明文聊天日志；文字在加密库里，我们主要用的是图片缓存。
- 没在 Mac 上点开、未加载高清的图，可能只有 `_THUMB` 或根本不在缓存里——这也是很多月份找不到工资条的原因。

#### 图片缓存用法

可读图片缓存（已按月分目录）：

```text
.../Caches/Images/YYYY-MM/
```

- 明文 JPG/PNG；优先 `_HD`，跳过 `_THUMB`
- `Messages1/Info.db`、`Session.db` **加密**，无法可靠按联系人过滤
- 缓存 = 该账号下各会话图片，**不保证**只有梁蓝欣
- 本地月份目录目前大约从 **2023-04** 起；**2022 / 2021 无缓存**
- 另有异常目录 `1970-1`（时间戳错乱），扫过无 2021–2022 工资条

项目内已拷贝约 38 个月、571 张左右到 `phone/梁蓝欣_全部聊天图片/YYYY-MM/`。

**一句话：** 手机聊天同步到 Mac 企微后，客户端把数据落在 `~/Library/Containers/com.tencent.WeWorkMac/...`；本项目主要用其中的图片缓存，不是手机系统日志。

## 4. 工资条筛选规则（后续重扫请沿用）

1. **形态**：长窄横条，典型约 `1200–1400 × 49`（很高宽高比）
2. **OCR 关键词（新旧表头兼容）**  
   - 新：`基本工资`、`保密费`、`代缴社保`、`全勤奖` …  
   - 旧：`实发基本工`、`实发保密`、`代扣社`、`实发合计`、`工资明细` …
3. **表头被裁**：含「常会洁」+ ≥6 个 `x.xx` 金额，且带「客服 / 正式 / 2013」等，也算命中
4. **每月 1 张**；命中后复制到 `梁蓝欣_工资条/<月>/工资条_<原文件名>`
5. OCR：本机 `paddleocr`（PP-OCRv5 mobile det/rec）；大月勿全量 OCR，先筛长窄再识别

## 6. 后续怎么继续

### 补齐缺失月份

1. 打开 **Mac 企业微信** → 梁蓝欣会话  
2. 翻到目标月份，**点开工资条图片**让高清进缓存（`Caches/Images/YYYY-MM/`）  
3. 对新出现的月份目录重跑「长窄优先 + OCR」逻辑，写入 `梁蓝欣_工资条/`  

### 补 2022 / 2021

当前 Mac 缓存没有这些年目录。需在客户端把历史聊天往上同步/打开到对应年份，确认 `Caches/Images/` 出现 `2022-*` / `2021-*` 后再扫。

### 聊天消息整体备份（非明文导出）

企微无官方明文导出；消息库加密。可行做法：

1. **退出企微**后备份整个 Profile：  
   `~/Library/Containers/com.tencent.WeWorkMac/Data/Documents/Profiles/204D5660AC6464CD45F5EFBC53C6AC1A/`  
   （重点：`Messages1/`、`Caches/Images/`、`Contact/`、`collection/`）
2. **另存可读内容**：本目录 `梁蓝欣_全部聊天图片/` + `梁蓝欣_工资条/`（真正能直接打开看）
3. 重要内容可在客户端「收藏」或转发文件传输助手再另存

示例：

```bash
# 先完全退出企业微信
ditto ~/Library/Containers/com.tencent.WeWorkMac/Data/Documents/Profiles/204D5660AC6464CD45F5EFBC53C6AC1A \
  "/Users/weichaofan/Documents/洁-工作/wechat_qiye/wework_profile_backup_$(date +%Y%m%d)"
```

## 8. 踩坑备忘

- 手机相册 `WeixinWork` ≠ 聊天月分组  
- 按保存时间分月不可靠  
- 旧工资条表头是「实发基本工 / 实发保密」，只用「基本工资」会漏检  
- 有的图只有数据行（如 2023-07 的 `1248×23`），需用「姓名 + 金额行」规则  
- 大月（如 2024-05/06）全量 OCR 极慢，务必先筛长窄候选  
- `1970-1` 目录时间乱，不要当历史年份来源
